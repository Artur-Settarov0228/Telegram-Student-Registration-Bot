# Telegram Student Registration Agent Skills

Ushbu skill Telegram Userbot orqali qatnashuvchilarni ro'yxatga olish va Telegramdan kelgan yangi ma'lumotlarga qarab aqlli, insoniy tarzda javob berish bo'yicha qoidalarni ta'minlaydi.

## Core Capabilities
1. **Dynamic Message Adaptation**: Telegramdan foydalanuvchi qanday yangi ma'lumot bersa (savol, shahar, ta'lim muassasasi, oraliq istaklar), bevosita o'sha yangi ma'lumotga qarab javob berish.
2. **In-Flight Corrections**: Ma'lumotlar o'zgarganda yoki xato kiritilganda darhol yangilash.
3. **Conversational Memory**: 6-turnlik suhbat tarixini xotirada saqlash va kontekstni uzmaslik.
4. **Natural Uzbek Language**: Qisqa (1-2 gap), samimiy va hurmatli o'zbek tilida muloqot qilish.
5. **Deterministic Google Sheets Persistence**: Ma'lumotlarni dublikatsiz saqlash.
